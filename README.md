# Kolipaka Venkata Sai - Portfolio

Static portfolio website (HTML, CSS, vanilla JavaScript). No build step.

## Structure
```
index.html          Page markup
css/style.css       Styles
js/data.js          >>> Edit this to change your content (profile, skills, projects, certificates)
js/main.js          Builds the page from data.js
js/effects.js       Animations / visual effects
assets/images/      Profile photo and project images
assets/certificates Certificate images
assets/docs/        PDFs
```

## Run locally
Open `index.html` in a browser, or run `python -m http.server` and visit http://localhost:8000.

## Deploy on GitHub Pages (free)
1. Create a repository named `KolipakaVenkatasai.github.io` (or any name).
2. Upload all files in this folder (keep `index.html` at the repo root).
3. Repo **Settings -> Pages -> Source: Deploy from a branch -> main / (root)** -> Save.
4. Your site goes live at `https://KolipakaVenkatasai.github.io/` (or `/<repo-name>/`).

Alternatives: Netlify Drop, Vercel, or Cloudflare Pages - drag and drop this folder.
